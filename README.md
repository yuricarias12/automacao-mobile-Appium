# 📱 Mobile Test Automation

## Java + Appium + Sauce Labs ☁️

Projeto de estudos voltado para automação mobile utilizando Java + Appium com execução local e integração com Device Farm da Sauce Labs.

</div>

---

# 🚀 Sobre o projeto

Este projeto foi iniciado em **2024** com foco em estudos de automação mobile utilizando **Java + Appium**.

Inicialmente, os testes eram executados localmente através do **Android Studio** e emuladores Android. Recentemente, o projeto foi retomado e atualizado para suportar execução remota utilizando o **Device Farm da Sauce Labs**, permitindo a execução dos testes em ambiente cloud. ☁️📱

O objetivo do projeto é aprofundar conhecimentos em:

✅ Automação mobile
✅ Estruturação de frameworks de testes
✅ Execução distribuída
✅ Integração com Device Farm
✅ Execução de testes em nuvem
✅ Evolução contínua de arquitetura de automação

# ⚙️ Pré-requisitos

Antes de executar o projeto localmente, é necessário possuir instalado:

* ☕ Java JDK 11+
* 📦 Maven
* 🤖 Android Studio
* 📱 Android SDK
* 🔌 Appium
* 🟢 Node.js
* 📲 Emulador Android configurado

---

# ▶️ Execução local

Execute os testes localmente utilizando:

```bash
mvn test
```

Certifique-se de que:

✅ O Appium Server esteja em execução
✅ O Android Emulator esteja iniciado
